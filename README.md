# Expiry Finder

A simple Java application to help shops manage product expiry dates.  
⚠️ This is a school project and **not production‑ready**.

## 🚀 How to Run

1. Download or clone this repository  
2. Navigate into the project folder:
   ```bash
   cd Expiry-Finder
   ```
3. Run the application (_Expecting Maven Already Installed_)
4. ```bash
   mvn clean compile
   mvn exec:java
   ```

> Have a Nice Day 😊
